# Hi, I'm Rusiru Anupama Rasanjana

I'm a third-year Electronic and Telecommunication Engineering undergraduate at the University of Moratuwa, Sri Lanka. My current focus is on machine learning, signal processing, robotics, and embedded systems.

I like working on projects where software has to meet real hardware: robot control, sensor processing, PCB design, firmware, and ML pipelines for practical engineering problems.

- Signal processing for sensing and perception

## Projects I want to highlight

### LumonBot - 6-axis cable-driven parallel robot
Ongoing robotics project focused on kinematics, workspace analysis, trajectory planning, control, and multi-actuator coordination.

Related repositories:
- Simulation/control: https://github.com/Team-Lumon/cdpr-vibe-coded
- PCB design: https://github.com/Team-Lumon/Lumon_Bot_PCB
- Motor controller firmware: https://github.com/Team-Lumon/Lumon_Bot_MotorDriver_Firmware
- Documentation: https://github.com/Team-Lumon/Lumon_Bot_Documentation

### N1K0 - Micromouse robot
Maze-solving robot project involving wall detection, fast-run optimization, IMU circuitry, sensor feedback processing, calibration, and Kalman-filter-based sensor fusion.

Repository: https://github.com/N1K0-micromouse/n1k0_micromouse

### ECG arrhythmia detection
Applied machine learning and signal processing project for cardiac signal classification. My work included changing the base model from ResNet101 to EfficientNet-B0 and adding SMOTE and Focal Loss to handle class imbalance.

Repository: https://github.com/hasith2003/ECG-arrhythmia-detection

### Analog function generator
Electronics project involving analog waveform generation, signal conditioning, PCB design, mechanical enclosure work, and output validation.

Repository: https://github.com/rus1ru/Function-Generator-EN2091

### SmartSense - motion-based auto shut-off device
Embedded systems project using MPU6050 motion sensing, ESP32 firmware, ESP-NOW communication, FreeRTOS task structure, PCB design, and hardware/software testing.

Repository: https://github.com/rus1ru/SmartSense-EN1190
