# Hi, I'm Rusiru 👋

I'm **Rusiru Anupama Rasanjana**, an Electronic and Telecommunication Engineering undergraduate at the **University of Moratuwa**.

I work across **robotics, embodied AI, computer vision, signal processing, and embedded systems**, with a particular interest in connecting perception, reasoning, and control on resource-constrained robotic systems.

### Selected Projects

* 👁️ **[VLM Egocentric Spatial Reasoning](https://github.com/rus1ru/embspatial-benchmark-pipeline)**
  Evaluation pipeline for **Qwen2.5-VL-3B** on EmbSpatial-Bench, studying how compact VLMs reason about **left/right, above/under, and close/far relationships** for assistive-robotics scene understanding.

* 🤖 **[ROS 2 Omni-Directional Mecanum Robot](https://github.com/rus1ru/omni_directional_ros2_implementation)**
  ROS 2 Jazzy autonomy stack with **Gazebo Harmonic, SLAM Toolbox, Nav2, ros2_control, LiDAR, and holonomic Mecanum navigation**.

* 🧠 **[DFWild — Spatial–Frequency Deepfake Detection](https://github.com/rus1ru/DFWild-Light)**
  Lightweight deepfake detector combining **MobileNetV3-Small** spatial features with **FFT, Haar-wavelet, and Laplacian forensic features**. Spatial–frequency fusion reached **0.9622 validation AUROC** with ~**1.13M parameters**.

* 🕸️ **[LumonBot](https://github.com/orgs/Team-Lumon/repositories)**
  6-axis cable-driven parallel robot. Worked on **actuator-control PCB design, ESP32 firmware, CAN communication, stepper control, magnetic-encoder feedback, and hardware integration**.

* 🐭 **[N1K0 Micromouse](https://github.com/N1K0-micromouse/n1k0_micromouse)**
  Autonomous maze-solving robot with **low-noise sensor-interface PCB design, ToF sensing, IMU/encoder fusion, and Kalman-filter-based state estimation**.

* 📈 **[MotorSense](https://github.com/rus1ru/motor-sense)**
  PyTorch vibration anomaly-detection pipeline using **Dense and Conv1D autoencoders**, raw vibration signals, and FFT-domain features for predictive-maintenance experiments.

* 🔌 **[SmartSense](https://github.com/rus1ru/SmartSense-EN1190)**
  ESP32/FreeRTOS-based automatic mains shut-off system with **MPU6050 sensing, ESP-NOW communication, isolated power-control electronics, and custom Altium PCBs**.
